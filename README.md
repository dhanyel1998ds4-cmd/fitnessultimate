# Hyperfit

Landing page responsiva inspirada na referência Hyperfit, implementada em HTML, CSS e JavaScript sem dependências de runtime.

## Executar

```bash
npm run dev
```

Abra `http://127.0.0.1:43117`.

## Verificação

```bash
npm run check
```

A experiência inclui navegação sticky, reveals por scroll, planos alternáveis, carrossel de depoimentos, FAQ em acordeão, formulário com confirmação, modal de vídeo e menu mobile.
